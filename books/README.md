# books: the standard textbooks (stays on this computer)

Put the textbooks your group follows here, one folder per subject:

```
books/
  anatomy/        for example bd-chaurasia-vol-1.pdf, vishram-singh-upper-limb.pdf
  physiology/     for example guyton-hall.pdf, ak-jain-vol-1.pdf
  biochemistry/   for example vasudevan.pdf, satyanarayana.pdf
```

Any file name works. For each book, tell Claude the title, author and edition, and which chapters
to start with (your college's teaching order is best).

## How the books are used

- Each topic in MedLearn OS is written once, in our own words, from all the standard books
  together: a short lesson, key facts, questions and recall cards.
- Every topic lists where each book covers it (book, edition, chapter, pages), so everyone can
  read it in the book they follow. Each student picks their books under My books, and the app
  shows theirs first.
- Where the books differ, the topic says so.

## Privacy and copyright

The books are copyrighted. Git ignores everything in this folder except this note, so the PDFs
are never uploaded to GitHub. They are read only to prepare the group's own study notes, which
cite the books and do not copy their text or figures. The app stays invite-only while it holds
these notes.
