On 27 Sep 2026 the user said the app is, for now, only for their own group of about 5 people, and content should come from a few standard textbooks they follow ("already standardised data books"). They will send the book details and PDFs on 28 Sep 2026 so content work can start.

**Why:** fastest route to real content; the public/commercial plan (provenance registry, licence gate, public topic pages, pilot with colleges) is not the immediate goal.

**How to apply:**
- Book text and figures are copyrighted: treat book-derived content as private-use only. Keep the deployed app invite-only (today topic pages are public and no login is required, so this must change before book content goes online), keep the repo private, never expose it on public or SEO pages.
- Prefer learning objects written in our own words (summaries, key facts, questions, cards) that cite book, edition, chapter and page, over pasting book text or figures.
- Mark book-derived content separately from future canonical/licensed content, so it can be replaced before any wider launch.
- Scanned PDFs need OCR or page-by-page reading; ask which chapters come first.
