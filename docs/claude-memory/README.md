# Claude's project notes

A copy, taken 8 October 2026, of the notes Claude Code keeps about this project between sessions:
the user's preferences, the design and 3D directions, engineering standards, book page offsets,
licence decisions and where the work stands. `MEMORY.md` is the index; each other file is one
note.

Claude keeps these outside the repository, per computer, in
`%USERPROFILE%\.claude\projects\<project folder>\memory\` (the project folder is the checkout's
path with `\`, `:` and spaces turned into `-`, for example `D--Dev-Workspace-MedLearn-OS`). To
carry them to another computer, open the project once in Claude Code there, then copy these files
into that folder; or ask Claude to read `docs/claude-memory/` at the start of a session.

They are notes, not specifications: the code, the README and the plans in `docs/` win where they
differ.
